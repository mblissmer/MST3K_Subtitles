# MST3K_Subtitles
## The Unofficial MST3K "Good Enough Subtitles" Project

This is a repository for SRT subtitle files for all "classic" Mystery Science Theater 3000 episodes (Seasons 1-10).
This was started after the announcement of the Gizmoplex shutting down, as a way to catalog the best versions of subtitles for each episode as we can.
Subtitles for MST3K episodes offers a pretty unique challenge:
* riffers frequently talk over movie dialog
* sometimes it's not clear who said what
* movies with bad audio tracks can have frequent unintelligible lines

There is another effort to "burn-in" subtitles (captions), located here: https://www.youtube.com/@MST3kCaptions/videos
This is a really great project with really high ambitions.
They have color-coded subtitles, coordinated with who is speaking,as well as animated subs during the host segment transitions. It's really impressive.

Here, we're going for a lower-effort, maximum-effect angle. The goal is to have the subtitles as SRT files, which offer no color, no animation, and are the most compatible format with pretty much any setup or file. Also, we're not strictly going for 100% accuracy. Hence the title of the project. 
If we can get every single episode here and accurate to like 70%, that would be HUGE, and also... importantly... Good Enough (tm).


## How to use:
Download all files and place them beside your video files. 
They must have exactly the same filename as your video file (except for the file extension of course)
